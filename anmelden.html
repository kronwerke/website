Anmelden

Mit deinem Minecraft-Konto, ohne Passwort. Du verbindest dich kurz mit unserem Anmelde-Server und bekommst einen Code. Einen Platz auf der Whitelist brauchst du dafür nicht.

    Minecraft Java ab Version 1.20.2 starten, dann Mehrspieler und Server hinzufügen mit dieser Adresse:

  2. Verbinden

    Du wirst sofort wieder getrennt, und auf dem Bildschirm steht dein Code mit sechs Zeichen. Er gilt zehn Minuten.

Was dabei passiert

Beim Verbinden meldet sich dein Spiel bei Mojang an wie bei jedem Server. Unser Anmelde-Server fragt Mojang, ob das wirklich dein Konto war, und zeigt dir dann den Code. Dein Passwort sieht dabei niemand außer Mojang.

Du bleibst auf diesem Gerät sechs Monate angemeldet, und jeder Besuch verlängert das wieder auf sechs Monate. Solange behalten wir deinen Minecraft-Namen und deine UUID. Abmelden löscht beides sofort. Mehr dazu im Datenschutz, Abschnitt 3a.
