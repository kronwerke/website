Install

Ready to play in five minutes. What do you play Minecraft with?

You need Minecraft Java Edition and a PC with at least 16 GB of memory. The page asks the server which version of the pack it runs: current. The links below always lead to exactly that version.

In game, menus, hints and items are in English. The quest book is German for now; an English one follows.

First the Modrinth App

The normal Minecraft launcher cannot run modpacks. The Modrinth App is free, needs no account of its own and takes care of Java and NeoForge.

0 of 3 steps

Updates: the version the server wants is at the top of this page. When it is newer than yours, import the new file the same way. The world lives on the server, nothing gets lost.

It does not work without a modpack app, but the Modrinth App is installed in two minutes.

How much memory?

The pack needs a lot of memory, but not all of it: Windows and your browser want to live too.

Not working?

Most problems are too little memory. If that does not help, ask on the Discord and attach the file logs/latest.log from your instance. More in the questions.
