Installieren

In fünf Minuten im Spiel. Womit spielst du Minecraft?

Du brauchst Minecraft Java Edition und einen PC mit mindestens 16 GB Arbeitsspeicher. Welche Version das Pack gerade hat, holt sich die Seite vom Server: aktuell. Die Links unten führen immer zu genau dieser Version.

Erst die Modrinth App

Der normale Minecraft-Launcher kann keine Modpacks. Die Modrinth App ist kostenlos, braucht kein Konto und erledigt Java und NeoForge selbst.

  1. Herunterladen

    Auf modrinth.com/app die App für dein System laden und installieren.

  2. Mit Microsoft anmelden

    Beim ersten Start mit dem Microsoft-Konto anmelden, mit dem du Minecraft gekauft hast.

  3. Weiter

Modrinth App

  1. Pack laden

    Kronwerke Season 2 (.mrpack) herunterladen.

  2. Importieren

    In der App links auf +, dann oben Import from file und die heruntergeladene Datei wählen. Die App lädt jetzt rund 600 MB Mods, das dauert ein paar Minuten.

  3. Speicher einstellen

    Die Instanz öffnen, oben rechts auf das Zahnrad, Java and memory, und den Speicher auf 8 GB stellen. Mit den voreingestellten 2 GB startet das Pack nicht richtig.

  4. Spielen

    Starten, Multiplayer, Server hinzufügen, als Adresse 93.90.74.243 eintragen.

Updates: Welche Version der Server gerade will, steht oben auf dieser Seite. Ist sie neuer als deine, die neue Datei genauso importieren. Die Welt liegt auf dem Server, da geht nichts verloren.

CurseForge App

  1. Pack laden

    Kronwerke Season 2 (.zip) herunterladen.

  2. Importieren

    In der App bei Minecraft auf Create Custom Profile, dann unten Import und die Zip-Datei wählen.

  3. Speicher einstellen

    Zahnrad unten links, Minecraft, Java Settings, Allocated Memory auf 8 GB (8192 MB).

  4. Spielen

    Profil starten, Multiplayer, Server hinzufügen, als Adresse 93.90.74.243 eintragen.

Prism Launcher

  1. Importieren

    Add Instance, links Import, und diese Adresse einfügen: https://github.com/kronwerke/pack/releases

  2. Speicher einstellen

    Instanz bearbeiten, Settings, Java, Maximum auf 8192 MB.

  3. Spielen

    Starten, Multiplayer, Server hinzufügen, als Adresse 93.90.74.243 eintragen.

Updates: Welche Version der Server gerade will, steht oben auf dieser Seite. Ist sie neuer als deine, die neue Adresse genauso importieren.

Klappt nicht?

Die meisten Probleme sind zu wenig Speicher. Hilft das nicht, frag im Discord und häng die Datei logs/latest.log aus deiner Instanz an. Mehr dazu in den häufigen Fragen.
